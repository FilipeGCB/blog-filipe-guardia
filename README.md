## Em 10 segundos

Este repositório mantém meu **site pessoal, artigos e portfólio público**. A ideia é mostrar não só o que eu estudo, mas principalmente o que eu construo, testo, documento e aprendo na prática.

**Site:** [filipegcb.github.io/blog-filipe-guardia](https://filipegcb.github.io/blog-filipe-guardia/)

## Projetos públicos em destaque

- **[Cognitive OS](https://github.com/FilipeGCB/cognitive-os)** — uma Agent Skill para amadurecer decisões antes de ações consequenciais, separando evidência, hipótese, risco e próxima prova útil.
- **[Fil-Harness](https://github.com/FilipeGCB/fil-harness)** — um control plane para agentes de código: eles podem executar trabalho, mas não podem conceder a si mesmos autoridade para aprovar o próprio resultado.
- **[Visual Presentation Studio](https://github.com/FilipeGCB/visual-presentation-studio-public)** — sistema de engenharia para projetar, construir, renderizar, inspecionar e validar apresentações e narrativas visuais com IA assistida.
- **[Guard.IA Live](https://github.com/FilipeGCB/guardia-live)** — copiloto local-first para acompanhar reuniões em tempo real, organizar contexto e apoiar a conversa sem tornar a nuvem obrigatória.

Esses projetos representam frentes diferentes da mesma evolução: **entender o problema → estruturar decisão → construir sistema → verificar resultado → governar execução**.

## Sobre mim

Minha base profissional vem de operações, planejamento, dados e cobrança. Ao longo do tempo, essa experiência passou a se combinar com automação, desenvolvimento de software, IA generativa, agentes e arquitetura de soluções.

O ponto central do meu trabalho é transformar contexto real — regras, exceções, riscos e objetivos — em sistemas que possam ser usados, verificados e evoluídos.

## Projetos privados

Parte do meu trabalho permanece privada por envolver produto comercial, infraestrutura, segurança, dados ou propriedade intelectual. Nesses casos, o blog publica somente o contexto necessário para explicar o problema, a abordagem e as competências demonstradas, sem expor material sensível.
