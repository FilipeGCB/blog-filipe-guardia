Private Beta

Fil Desktop Commander

Um plugin experimental para permitir que o ChatGPT trabalhe em um computador autorizado — arquivos, terminal e fluxos de desenvolvimento — mantendo autenticação e permissões separadas por usuário e dispositivo.

Baixar plugin Private Beta ↓ Como instalar
Versão de teste • acesso controlado

O que esta versão faz

O pacote instala a integração do Fil Desktop Commander no ChatGPT. O download não contém senhas, tokens pessoais nem acesso prévio a qualquer computador.

Identidade
Cada pessoa autentica a própria conta.
Dispositivo
O acesso depende de um computador explicitamente autorizado para aquela identidade.
Permissões
Leitura, escrita, terminal e outras capacidades continuam sujeitas às políticas do servidor e do dispositivo.
Objetivo do beta

Testar isolamento de contas

Esta distribuição existe primeiro para validar uma segunda conta do ChatGPT em uma Windows VM antes de liberar o uso para outras pessoas.

Conta A
Não deve herdar sessão, token ou autorização da Conta B.
Computadores
Cada dispositivo deve aparecer apenas para os usuários que receberam autorização.
Revogação
O acesso deve poder ser retirado sem reinstalar o plugin.

Instalação

Como testar no ChatGPT

Use esta versão somente em contas e máquinas de teste autorizadas enquanto o beta estiver em validação.

01

Baixe

Faça o download do ZIP desta página sem descompactá-lo.

02

Importe

No ChatGPT, abra Plugins e importe o pacote baixado.

03

Conecte

Faça a autenticação usando a conta que será testada.

04

Valide

Confirme que somente o dispositivo autorizado aparece e responde.

Aviso de segurança

Não é um acesso genérico ao computador

O plugin é apenas a camada de integração. A autorização efetiva é verificada no servidor MCP e no agente do computador. Instalar o mesmo ZIP em outra conta não concede automaticamente acesso às máquinas de outro usuário.

Private Beta: esta versão ainda está em teste controlado e não deve ser redistribuída como produto público final.

Teste atual: o pacote usa o Secure MCP Tunnel da OpenAI que já atende o ambiente do Filipe. A instalação em uma segunda conta independente é justamente o que está sendo validado nesta versão; se o ChatGPT bloquear o túnel fora do workspace de origem, a próxima versão migrará a conexão para um endpoint MCP HTTPS compartilhável, mantendo OAuth e autorização por usuário/dispositivo.
