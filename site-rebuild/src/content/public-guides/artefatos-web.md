# Artefatos Web Visuais e Interativos

Constrói sites, dashboards, simuladores e experiências HTML com comportamento real e QA verificável.

## Quando ativar

- o entregável principal é HTML ou aplicação web
- interação e responsividade importam
- há conteúdo, dados ou processo a representar

## Quando não ativar

- o pedido é apenas texto ou documento Office
- não há insumo suficiente para definir o artefato
- o ambiente não permite nem produzir código nem entregar arquivos

## Entradas mínimas

- objetivo e público
- conteúdo ou dados
- referências visuais
- restrições técnicas e de publicação

## Processo obrigatório

1. definir comportamento e critérios de aceite
2. construir estrutura semântica
3. implementar interação progressivamente
4. testar responsividade, teclado e erros
5. entregar arquivos e evidências

## Entrega esperada

- artefato web funcional
- arquivos organizados
- instruções de execução
- relatório de testes

## QA e limites

- não entregar apenas mockup quando foi pedido sistema funcional
- evidenciar interações críticas

## Regra de execução

Aplicar também [`00-KERNEL-EXECUCAO.md`](./00-KERNEL-EXECUCAO.md).
