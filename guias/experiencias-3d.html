O que faz

Para que este método existe

Cria aplicações 3D somente quando profundidade ou posição carregam significado.

Quando usar

Quando este método faz sentido

O eixo Z ajuda a compreender relações; não use 3D apenas por espetáculo quando 2D for mais claro.

Entradas

O que fornecer ao assistente

Significado espacial, dados, dispositivos-alvo e limites de GPU e acessibilidade.

Processo

Como o trabalho deve avançar

  1. Executar capability check.
  2. Justificar o uso de 3D.
  3. Projetar cena, câmera e interação.
  4. Entregar alternativa 2D equivalente.
  5. Adaptar qualidade ao dispositivo.
Entrega

Resultado esperado

Experiência 3D, fallback 2D e relatório de compatibilidade.

Qualidade

Gate de qualidade

3D precisa melhorar a compreensão e ter alternativa acessível.

Exemplos

Como pedir

  • “Visualize estas relações em 3D porque a profundidade é parte do dado.”
  • “Projete uma experiência WebGL com fallback 2D equivalente.”
Onde usar

O mesmo método em níveis diferentes

Use o agente portátil quando você só tem um chat com suporte a arquivos ou contexto Markdown. Use o guia mestre quando quiser estudar/adaptar o método. Uma Skill instalável só deve ser oferecida quando existir um pacote real e testado para esse método.
