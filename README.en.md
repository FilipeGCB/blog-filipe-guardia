## Featured public projects

- **[Cognitive OS](https://github.com/FilipeGCB/cognitive-os)** — an Agent Skill for maturing decisions before consequential action by separating evidence, hypotheses, risks, and the next useful proof.
- **[Fil-Harness](https://github.com/FilipeGCB/fil-harness)** — a control plane for coding agents: they may execute work, but they cannot grant themselves authority to approve their own result.
- **[Visual Presentation Studio](https://github.com/FilipeGCB/visual-presentation-studio-public)** — an engineering system for designing, building, rendering, inspecting, and validating AI-assisted presentations and visual narratives.
- **[Guard.IA Live](https://github.com/FilipeGCB/guardia-live)** — a local-first copilot for following meetings in real time, organizing context, and supporting the conversation without making cloud services mandatory.

These projects represent different parts of the same progression: **understand the problem → structure the decision → build the system → verify the result → govern execution**.

## About me

My professional foundation comes from operations, planning, data, and collections. Over time, that experience began to combine with automation, software development, generative AI, agents, and solution architecture.

The common thread in my work is turning real context — rules, exceptions, risks, and goals — into systems that can be used, verified, and improved.

## Private projects

Some of my work remains private because it involves commercial products, infrastructure, security, data, or intellectual property. In those cases, the blog publishes only enough context to explain the problem, approach, and demonstrated skills without exposing sensitive material.
